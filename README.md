# Grafos

A Teoria dos Grafos é um campo dentro da matemática dedicado a estudar relações entre elementos de um conjunto. Essas relações são representadas por estruturas conhecidas como grafos, denotados por G(V,A), em que V é um conjunto de vértices e A um subconjunto de arestas. 

Essa teoria sustenta muitas estruturas de dados e algoritmos usados para representar redes como a internet, sistemas de comunicação e gps. 

# Exercícios

As pastas “Grafo_Listas_Adejacências” e “Grafo_Matriz” contém as implementações dos grafos e a resolução dos exercícios abaixo: 

1. Verificar se as arestas de g2 estão contidas em g1 

2. Criar uma cópia de um grafo 

3. Criar uma cópia transposta de um grafo  

4. Transformar grafo dirigido em não dirigido 

5. Verificar se dois grafos implementados através de listas de adjacências são idênticos 

6. Verificar se dois grafos com implementações diferentes idênticos 

7. Verificar se o vértice "fim" é alcançável a partir do vértice "i" 

8. Faça um algoritmo para exibir ciclos de um grafo 

9. Quantos vértices são alcançáveis a partir de um vértice i? 

10. Retornar uma lista ligada em que os vértices representam países em que é possível viajar sem visto 

11. Verifique se é possível viajar de A até B usando apenas voos da companhia x 

12. Converter um grafo matriz em listas de adjacências 

13. Verifique se há um caminho de a até b passando por x 

14. Exibir até N salas com capacidade >= x, alcançáveis a partir de um início i 

15. Verifique se há um caminho de a até b que não passe por x 

16. Encontrar posto de gasolina mais próximo representado por x 

17. Verificar a quantidade de laços em um grafo 

18. Remover laços de um grafo 

19. Escreva um algoritmo para destruir as arestas de um grafo, tornando-o vazio
